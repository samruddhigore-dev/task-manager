# 📝 Task Manager App

A simple and clean desktop Task Manager built using Python and Tkinter.

## 🚀 Features
- Add tasks
- Delete tasks
- Mark tasks as completed
- Dark themed UI

## 🛠️ Tech Stack
- Python
- Tkinter

## ▶️ How to Run
1. Clone the repository
2. Open terminal in project folder
3. Run:

```bash
python main.py
